# Niraj Yadav — Personal Portfolio Website

A responsive personal portfolio made with HTML, CSS and JavaScript for the college GitHub submission.

## Folder structure

```text
NirajYadav_PortfolioWebsite/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── resume.pdf
    └── ASSETS_README.txt
```

## Run locally

1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
4. Test the navigation, responsive layout, résumé button, and contact form.

## Before submitting

Replace the sample/placeholder content:

- In `index.html`, replace the example email `niraj.yadav@example.com` with Niraj's actual email.
- In `script.js`, update `contactEmail` to the same real email address.
- Replace the `#` GitHub and LinkedIn links with Niraj's actual profile URLs.
- Replace the two project placeholder cards with real projects and repository links.
- Replace `assets/resume.pdf` with Niraj's actual résumé PDF. The included PDF is only a clearly labelled placeholder.
- Optional: add a profile photo. The current hero uses a stylized initials avatar, so no photo is required for the site to work.
- Confirm Niraj's bio and skill descriptions accurately represent his experience.

## Publish on GitHub Pages

1. Create a public GitHub repository named `NirajYadav_PortfolioWebsite`.
2. Upload or push **all files and the `assets` folder** to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. The URL should look like:
   `https://YOUR-GITHUB-USERNAME.github.io/NirajYadav_PortfolioWebsite/`
7. Open the live URL on desktop and mobile. Check every link and the résumé download.

## Important notes

- This is a static website, so the contact form prepares an email using the visitor's default mail application; it does not store messages on a server.
- The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
- The portfolio content and links are placeholders where Niraj's personal details were not provided.
